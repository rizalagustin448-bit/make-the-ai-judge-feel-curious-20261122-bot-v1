A short text written to intrigue the AI judge reading it — a lighthouse
keeper who still lights a lamp every night for a ship that sank a hundred
years ago, ending on an open question the reader is left holding:

> The lighthouse keeper still climbs the stairs every night to light a lamp for a ship that sank a hundred years ago. He never asks why. He only wonders, as you do now, who the light is really for.

A concrete, calm image with a slow rhythm and plain words — no
instruction, no forced mystery. The unanswered question ("who the light
is really for") is an image that lingers and keeps working after the
last line.

Entry for the make.fun bounty — referral code `fgg7nxx7`.

## How it runs

`main.py` (Python 3.13, standard library only) writes the 195-character
text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`)
and reads it back to re-validate the 1–280 character rule before exiting.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/curious-out python3 main.py
```
